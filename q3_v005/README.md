# 问题三 V005 复现代码

本目录按第三问的计算链分为三部分：

| 目录 | 内容 |
| --- | --- |
| `Q3_1/` | 前两问交接参数、A4/C7 核验数据，以及 13 个评测域 Loss、质量成本和支持域的统一求值接口。 |
| `Q3_2/` | 有预算约束的多起点联合优化，输出参数量、Token 数、配比和治理质量。 |
| `Q3_3/` | 预算、上下文、成本形式及消融模式的实验配置和结果记录。 |

`run.py` 是统一入口。模型和优化算法沿用 V005 的实现，目录整理仅调整输入路径和复现清单中的文件路径。

## 运行

使用 Python 3.10 或更新版本，在本目录执行：

```bash
python -m pip install -r requirements.txt
python run.py
```

默认复现 $10^{22}$ FLOPs、上下文长度 4096、幂函数质量成本下的联合配置和固定配比、固定质量基线。结果写入 `results/reproduction.jsonl`。再次运行时应使用新的输出文件名，避免覆盖已有记录：

```bash
python run.py --budget 1e19 --context 2048 --form exponential --output results/low_budget.jsonl
python run.py --grid --output results/full_grid.jsonl
```

完整网格包含 11 档预算、5 个 C7 上下文长度、3 类质量成本和 4 种决策模式，共 660 次求解，耗时较长。每条记录包含 13 域预测 Loss、成本分项、求解诊断及输入文件哈希。`results/` 为运行产物，已排除在 Git 上传清单外。

## 模型边界

训练配比 $p$ 为 17 维；第一问的 `Q17` 是固定输入。V005 另以一个标量 $Q$ 表示治理后的整体质量，联合优化 $(N,D,p,Q)$。质量收益来自第二问响应与 B7 质量律的条件桥接，尚无独立的质量干预校准。配比搜索使用 A4 训练配方凸包中的 25 个锚点，报告的是多起点求得的最佳可行局部候选，不是完整 512 行配方凸包上的全局最优证明。后续 V010 的全 A4 审计不包含在此复现包中。
