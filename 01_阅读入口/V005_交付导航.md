## 代码与复核

使用指定环境`/ExtHDD/Apps/Anaconda/envs/llm_gnn/bin/python`。入口[运行第三问.py](运行第三问.py)是后来增加的交付与披露入口，不冒充历史实验入口；默认只打印帮助或执行计划，不自动重跑优化。

```bash
./运行第三问.py --list
./运行第三问.py check-sources
./运行第三问.py check-saved --execute
```

最后一条会复算本完整工作区的保存结果，可能处理16620条物理记录；只有精简阅读包而缺少原始JSON时不适用。历史注册矩阵在`results/registered_*.json`，科学程序在`02_代码与实验/`、`03_结果分析/`和`05_补充审查/`。旧准入和旧结果不由新脚本自动覆盖。

出版入口为[run_paper_build.py](03_论文工作区/run_paper_build.py)。它依赖已验证的本机工具链和实际W1回执，重建前须保留现有完整稿：

```bash
source /home/pz/F_code/F题/PZ_Q3/工具链验证/env.sh
"$DOC_PYTHON" -B 03_论文工作区/run_paper_build.py --approval ../qa/评审专家/15_W1最终回执.json --overwrite
```

重建会使旧成品W2绑定失效，必须对新文件重新验收；不把本命令等同于重新执行全部科学实验。
