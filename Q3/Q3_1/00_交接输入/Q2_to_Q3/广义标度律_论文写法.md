# 广义标度律：可直接写进论文的形式

本文件由 `Q2/Q_2_3/Q_2_3_2_handoff_paper_form.py` 从 `results/Q_1_to_2/generalized_scaling_compact.json` 生成，
与交付求值器逐位一致（最大偏差 7.1e-15）。记号做了两处等价整理：

1. **吸收参考规模**：把 `(N/N_ref)^(−η)(D/D_ref)^(−ζ)` 换成 `N^(−η)·D^(−ζ)`，`N_ref`、`D_ref` 并入配比项系数，正文不再出现；
2. **合并 α = β**：交付模型里两者是同一个数（0.293183），基线可写成「规模因子 × 配比因子」。


## 1. 主公式

```latex
L_k(N,D,\boldsymbol p) = E_k + N^{-\alpha}\Big[A_k + B_k\Big(\frac{D}{N}\Big)^{-\alpha}\Big] + N^{-\eta_k}D^{-\zeta_k}\,\Psi_k(\boldsymbol p),\qquad k = 1,\dots,13
```

其中 $N$ 为参数量、$D$ 为训练 token 数，**均以十亿（$10^9$）为单位**；$L_k$ 是第 $k$ 个评测域的验证交叉熵；$\boldsymbol p$ 是 17 维数据配比，$\sum_i p_i = 1$。

两项的读法：

- 基线 $N^{-\alpha}[A_k + B_k (D/N)^{-\alpha}]$：**只依赖规模 $N$ 与配比 $D/N$**，与数据配比无关；
- 配比项 $N^{-\eta_k}D^{-\zeta_k}\Psi_k(\boldsymbol p)$：$\Psi_k$ 是配比响应，$N^{-\eta_k}D^{-\zeta_k}$ 是它的**振幅随规模的衰减**。


## 2. 配比响应 $\Psi_k$

```latex
\Psi_k(\boldsymbol p) = \sum_{i=1}^{17} w^{pQ}_{k,i}\big(p_i Q_i - \bar m_i\big) + \sum_{i=1}^{17} w^{clr}_{k,i}\big(\mathrm{clr}_\varepsilon(p)_i - \bar m'_i\big)
```

```latex
\mathrm{clr}_\varepsilon(\boldsymbol p)_i = \ln(p_i+\varepsilon) - \frac{1}{17}\sum_{j=1}^{17}\ln(p_j+\varepsilon),\qquad \varepsilon = 0.001
```

$Q_i$ 是第 $i$ 个数据域的固定质量分（观测输入），$\bar m_i$、$\bar m'_i$ 是中心化常数 = 参考锚点训练配比上该特征的均值，作用是让 $\Psi_k$ 在参考配比上均值为 0（即 $\Psi_k$ 读作「相对平均训练配比的偏离」）。两段系数的完整数值见同目录 `generalized_scaling_law_paper_coefficients.csv`。

## 4. 精度与适用区间（论文里应一并给出）

| 项目 | 值 |

| 留出集 relative RMSE | 5.54% |
| 留出集中位 APE | 2.40% |
| 留出集配比项 $R^2$ | 0.9006 |
| 不可约下界 $E_k$ 未被击穿 | 是 |

观测支撑域：$N \in [10^{-3}, 1]$（十亿参数），$D \in [1, 25]$（十亿 token），配比熵 $H(\boldsymbol p)\in[0.008, 2.381]$。超出即外推。


## 5. 三条必须写进论文的限定

1. **$\eta_k$、$\zeta_k$ 没有留出检验**。每个评测域的振幅只在三个锚点上各有一个标量，两个非参考锚点恰好定出两个指数，曲线逐点穿过反演值、残差为零——这是插值不是验证。
2. **$Q_i$ 不可独立辨识**。数据集 A 中每个域的 $Q_i$ 固定，自由域系数可以把它的尺度整体吸收，所以本模型给的是**配比**响应，不是质量效应；质量弹性须取自 B6/B7。
3. **$w^{pQ}$、$w^{clr}$ 不可按域解读**。69% 的权重为负，而控制住配比多样性之后逐域归因会崩塌（排序 Spearman ≈ −0.10）；这些系数只用于预测，不能读成「哪个域质量高」的排序。
