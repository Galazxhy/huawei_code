# V005 重复来源一致性修订

V004独立复核发现：近似相等不是传递关系；相邻来源通过容差不能保证整组相容。质量方向在判定阈值两侧的微小差异还会改变机制资格。

1. 整组重复来源作两两比较；任何矛盾永久使该配置无效。合格代表由科学字段规范JSON最小字典序决定，候选比较历史保留全部原值，不被代表覆盖。
2. Q、Q0、p、均值Loss、成本份额和质量方向值参与阈值判断，要求精确一致；其余既有科学字段保持已声明容差。
3. accepted候选集合核对保持；运行时间、消息和候选顺序不属于科学冲突。分析模块另保留候选重复次数及起点数量，避免起点充分性判断漏检。
4. 增加三来源容差链的六种文件布局及两来源跨阈值反例，要求结果不依赖来源次序。

本版不改变模型、求解器、输入数据或实验矩阵。旧版冻结保留；本版独立M1/P1通过前不得执行全量。
